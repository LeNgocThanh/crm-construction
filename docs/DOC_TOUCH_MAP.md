# DOC TOUCH MAP

Muc tieu:
- Tra nhanh: sua module nao thi cap nhat doc nao.
- Giam viec phai mo va ra soat toan bo thu muc `docs/`.

## 1) Projects
- Neu sua tong quan module du an:
  - `PROJECT_MODULE_GUIDE.md`
- Neu sua truc:
  - `status`
  - `stage`
  - `milestone`
  - `active material plan`
  - `active labor plan`
  thi cap nhat:
  - `PROJECT_EXECUTION_AXIS_SPEC.md`
- Neu sua:
  - `/projects/[id]/diary`
  - diary report
  - diary manager
  - gallery viewer
  - bo loc
  - phan trang
  thi uu tien:
  - `PROJECT_MODULE_GUIDE.md`
- Neu nghien cuu / trien khai:
  - QA/QC
  - HSE issue
  - punch list
  - acceptance lien ket voi diary
  thi doc:
  - `PROJECT_QA_QC_HSE_PUNCHLIST_SPEC.md`

## 2) Labor
- Neu sua:
  - worker / crew / trade
  - roster du an
  - cham cong
  - cham cong tu nhat ky
  - payment batch / payment record

  - `LABOR_MODULE_GUIDE.md`

## 3) Work Suggestions / Notifications

## 4) Files / Upload / Media

## 5) Inventory
- Neu sua posted engine / stocks / transaction:

## 6) Estimate / Assembly / 2D / 3D
- Neu sua thao tac assembly / designer / preview:
  - `ESTIMATE_ASSEMBLY_DESIGN_GUIDE.md`
- Neu sua y nghia thong so block:
  - `ESTIMATE_BLOCK_PARAMETERS_GUIDE.md`
- Neu sua formula / basis / quantity / mapping:

- Neu sua buc tranh estimate tong:
  - `ESTIMATE_V2_BLUEPRINT.md`

## 7) Access Control
- Neu sua:
  - permissions
  - roles
  - authz helper
  - route migrate
  thi cap nhat:
  - `ACCESS_CONTROL_GUIDE.md`

## 8) System-Level Changes
- Neu thay doi lam anh huong lien ket giua nhieu module:
  - `SYSTEM_OVERVIEW.md`
- Neu thay doi diem vao docs:
  - `DOC_INDEX.md`

## 9) Quy tac nhanh
- Feature nho:
  - cap nhat 1-3 file docs chinh
- Feature giao 2 module:
  - cap nhat doc chinh cua tung module + `SYSTEM_OVERVIEW.md` neu can
- Neu khong chac:
  - mo `DOC_INDEX.md`
  - sau do doi chieu file nay de chon doc can sua
